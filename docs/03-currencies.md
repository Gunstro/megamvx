# Currencies: AF and MB

## Afro (AF)
- Stable currency pegged 1:1 to GBP/basket.
- For transactions 2.50% user to user payment
- Exchange to fiat conversion (12.5% fee - 20% to Megabuck Value).
- AF ↔ AF transfers enabled between user wallets.

## MegaBuck (MB)
- Growth currency from 20% company turnover.
- Earned via engagement; outperforms speculative assets.
- Punitive exchange: 5.50% fee when exchanged to Afro (20% recycled to MB value).
- Encourages holding for long-term wealth.

## ESCROW
- Escrow mechanism to alleviate fraud.
- Escrow rules setup by buyer & seller.
- When either side of the rules are met payment takes place which can be immediate and or have a string of requirements, either side.

## Integration
- Dashboard wallets for both.
- Conversion tools with fee transparency.
- Public profiles show net worth (AF + MB).
